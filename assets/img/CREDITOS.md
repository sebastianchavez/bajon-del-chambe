# Fotografías de referencia

Estas fotografías reales ilustran las categorías. No son imágenes del negocio
ni garantizan ingredientes, porciones o presentación. Variantes de una misma
categoría comparten fotografía hasta contar con las fotos propias de cada plato.

Los archivos se redimensionaron y comprimieron a JPEG; el sitio realiza un
recorte visual con `object-fit: cover`.
